# Laboratório 03 — VLANs Cisco

## Objetivo
Configurar VLANs em um switch Cisco 2960 utilizando o Cisco Packet Tracer.

## VLANs utilizadas
- VLAN 10 — ADMINISTRACAO
- VLAN 20 — FINANCEIRO

## Resultados
- Comunicação entre computadores da mesma VLAN: bem-sucedida.
- Comunicação entre VLANs diferentes sem roteamento: não realizada, conforme esperado.

## Ferramentas
- Cisco Packet Tracer
- Switch Cisco 2960
- Quatro computadores virtuais
